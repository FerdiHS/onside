# Purpose

Use this skill when preparing human-facing documentation and demo materials.

The goal is not to write bloated docs. The goal is to make the product understandable, demoable, and submission-ready.

Read `AGENTS.md` and existing docs first.

# Primary outputs

Typical outputs include:
- `README.md`
- `docs/demo-script.md`
- `docs/product-brief.md`
- short business summary
- short technical summary
- setup instructions
- submission notes

# Repository-specific framing

For this project, the main story is:
- football intelligence copilot

For hackathon materials, keep the demo short and ensure docs match the actual submission story and implemented scope.
